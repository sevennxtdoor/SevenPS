Get started

How to join

For Windows. It takes about five minutes, and you only do it once.

  1. Get the server address and certificate

    Ask on Discord (feelingsarefake or iseven_99) for the server's IP address and the file sevenps-ca.crt.

  2. Point the game to SevenPS

    Open Notepad as administrator, open C:\Windows\System32\drivers\etc\hosts and add these two lines at the bottom (use the IP you got):

    SERVER-IP www.growtopia1.com
SERVER-IP www.growtopia2.com

    Check it: ping www.growtopia1.com should answer with the server's IP. If the lines disappear, your antivirus removed them: add them again and allow the change.

  3. Install the SevenPS certificate

    Double-click sevenps-ca.crt → Install Certificate → Local Machine → Place all certificates in the following store → Trusted Root Certification Authorities → Finish.

    It's needed for the login window. The certificate is limited to the two addresses above and can't be used for any other website.

  4. Open the game and log in

    The SevenPS login window opens. Pick New account, choose a GrowID (3–18 letters or numbers) and a password. Next time, just log in.

Back to the official game? Delete the two lines from the hosts file (or put # in front of them), then restart the game.

Community

Rules

The same rules as /rules in game.

  1. No scamming

    Always trade with the trade window, never "drop first". Real Roulette Wheel results only come from a real spin, never from chat.

  2. Keep your password safe

    Never share it with anyone. Staff will never ask for it.

  3. No cheating

    No hacks, modded clients, bots, macros or auto clickers.

  4. No bug abuse

    Found a bug? Report it to staff instead of using it.

  5. Be polite

    No spamming, swearing, racism, insults or begging.

  6. Keep names clean

    World names, signs and GrowIDs must not be rude or offensive.

  7. Bet at your own risk

    Staff won't refund items or World Locks lost in casinos or bets between players.

  8. Respect everyone

    Staff decisions are final.

Breaking the rules can get you muted, cursed (sent to HELL), world banned or banned. Report players with wrench → Report, and type /mods to see which staff are online.
